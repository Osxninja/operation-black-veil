## Mission Brief

At 06:20 UTC on 14 October 2025, analyst Mara Venn missed a scheduled check-in after sending a cryptic fragment. A recovered digital trail points toward archived accounts, a synthetic map, conflicting timestamps, and a disputed public contract.

Reconstruct the trail, assess the intended recipient, estimate the planned meeting time and location, and write a careful intelligence assessment.

> **Everything in this exercise is fictional.** Names, organizations, records, and locations are invented. The `.test` domains are for training only. No external searching or real-world contact is needed.

## Run the interactive case dashboard

This repository includes a standalone, dependency-free 3D case dashboard in [`docs/index.html`](docs/index.html). To publish it with GitHub Pages:

1. Open the repository’s **Settings → Pages**.
2. Under the build and deployment section, choose **Deploy from a branch**.
3. Select the `main` branch and the `/docs` folder, then save.
4. Replace `YOUR-USERNAME` and `YOUR-REPOSITORY` in the dashboard link above with your GitHub username and repository name.
5. After Pages finishes publishing, open the link. You can tilt the dossier with your pointer or touch, flip the investigation cards, and scrub the fictional timeline.

The README itself cannot run a WebGL/JavaScript scene inside GitHub’s rendered page. The 3D effects run on the GitHub Pages site; the README links to that site.

## Quick Start

1. Download [`operation-black-veil-player.zip`](operation-black-veil-player.zip).
2. Extract it and open `README.md` inside the package.
3. Begin with `evidence/case_brief.txt` and verify the evidence hashes.
4. Keep a claim-and-evidence ledger as you investigate.

**Estimated effort:** 30 hours · **Mode:** offline · **Tools:** local text, spreadsheet, JSON, and image viewers.

## Investigation Modules

- Digital identity and account correlation
- Offline domain and archive pivots
- Synthetic image and grid interpretation
- Timeline reconstruction and UTC normalization
- Procurement record analysis and confidence assessment

## Evidence Standards

- Cite filenames and record IDs for material claims.
- Separate observation from inference.
- Convert times using only supplied UTC offsets.
- Seek independent corroboration; one account match is not proof of identity.
- Do not present a discrepancy as proof of fraud or claim the meeting happened without evidence.

## Final Report

Complete the answer sheet in the evidence pack. Include a claim/evidence table, confidence levels, an alternative hypothesis, and explicit limitations.
