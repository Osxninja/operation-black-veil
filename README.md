## ◈ MISSION // READ BEFORE DEPLOYMENT

Analyst Mara Venn missed a scheduled check-in after sending a cryptic fragment. Reconstruct the digital trail from synthetic accounts, archived records, a schematic map, conflicting timestamps, and a disputed contract.

> **Training simulation:** every person, organization, account, domain, and location is fictional. The .test domains are reserved for examples. Do not search for real people or contact real services.

## ◈ QUESTION TERMINAL // SELECT A FILE

Expand each checkpoint when you are ready. Submit evidence-backed answers; the solution key is not included here.

<details>
<summary><strong>03 / ENTITY LINK</strong> — What supplier code connects the archive record to the supplier register?</summary>

<details>

</details>

## ◈ TRADECRAFT // EVIDENCE RULES

<details>
<summary><strong>Open field rules</strong></summary>

1. Separate direct observations from inferences.
2. Correlate identities using independent evidence; a matching handle by itself is not proof.
3. Convert local times only with the offset supplied in the case files.
4. Treat the map as a fictional schematic, not real geodata.
5. A scheduled meeting is not proof that anyone attended.
6. A procurement discrepancy is not, by itself, proof of fraud.

</details>
